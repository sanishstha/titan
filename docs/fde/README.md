# FDE evidence kit

Templates for the customer-facing half of the project. Fill them with real sessions only. Never invent users, quotes or results.

| File | Use |
|---|---|
| `outreach-template.md` | Messages to find your first 2-3 users |
| `discovery-questions.md` | What to ask in a first call |
| `scope-template.md` | One-page scope after discovery |
| `feedback-log.md` | They said, I changed, result |
| `postmortem-template.md` | When something breaks in front of a user |
| `demo-scripts.md` | Non-technical and technical demo outlines |
| `pilot-summary.md` | Final honest write-up |

Interview framing: describe what you did plainly, what you learned, and what you expect would differ at a large enterprise customer. Do not overclaim.
